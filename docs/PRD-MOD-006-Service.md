# PRD: 用户服务与帮助中心模块

**模块编号**: MOD-006  
**优先级**: P1  
**所属版本**: MVP v1.0

---

## 一、模块概述

### 业务背景
- 用户在使用过程中会有各种问题和疑虑
- 快速、专业的客服支持直接影响满意度
- 线上自助服务可以降低客服压力，提升效率

### 核心服务类型
1. **帮助中心** - 常见问题与教程
2. **在线客服** - 实时对话支持
3. **工单系统** - 问题反馈与追踪
4. **用户反馈** - 建议与投诉收集

---

## 二、用户故事

### 用户故事 1: 查找常见问题答案
```
作为一个新用户
我想快速找到常见问题的答案
这样不用等待客服就能解决问题

验收标准:
✓ 帮助中心能搜索
✓ FAQ 按分类展示
✓ 每个答案清晰且有图/视频说明
✓ 答案能解决 80% 的新用户问题
```

### 用户故事 2: 紧急咨询客服
```
作为一个有紧急问题的用户
我想立即与客服沟通
比如宠物到了但寄养人没回应

验收标准:
✓ 能进入在线客服 (工作时间内)
✓ 工作时间外可留言
✓ 客服回复 < 5 分钟 (工作时间)
✓ 支持图片/视频上传
```

### 用户故事 3: 投诉服务质量
```
作为一个对服务不满意的用户
我想提交投诉
获得问题解决或赔偿

验收标准:
✓ 投诉流程简单 (< 1 分钟)
✓ 投诉后有工单号追踪
✓ 客服在 24 小时内响应
✓ 提供解决方案或赔偿方案
```

## 五、数据模型

### help_articles 表
```sql
CREATE TABLE help_articles (
  id CHAR(36) PRIMARY KEY,
  category VARCHAR(50),
  title VARCHAR(200) NOT NULL,
  slug VARCHAR(200) UNIQUE,
  content LONGTEXT,
  keywords VARCHAR(500) COMMENT '搜索关键词',
  
  is_published BOOLEAN DEFAULT FALSE,
  view_count INT DEFAULT 0,
  helpful_count INT DEFAULT 0,
  unhelpful_count INT DEFAULT 0,
  
  created_by CHAR(36),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP,
  
  INDEX idx_category (category),
  FULLTEXT INDEX ft_content (title, content)
);
```

### tickets 表
```sql
CREATE TABLE tickets (
  id CHAR(36) PRIMARY KEY,
  ticket_no VARCHAR(50) UNIQUE NOT NULL,
  
  user_id CHAR(36) NOT NULL,
  related_order_id CHAR(36) COMMENT '关联订单',
  
  category ENUM('预订','支付','寄养','取消','服务质量','紧急','其他'),
  title VARCHAR(200),
  description TEXT NOT NULL,
  
  priority ENUM('低','中','高','紧急') DEFAULT '中',
  status ENUM('待处理','处理中','待回复','已解决','已关闭'),
  
  assigned_to CHAR(36) COMMENT '分配给的客服',
  resolved_by CHAR(36) COMMENT '解决者',
  
  attachment_urls JSON COMMENT '附件 URLs',
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  resolved_at TIMESTAMP NULL,
  
  FOREIGN KEY (user_id) REFERENCES users(id),
  INDEX idx_status (status),
  INDEX idx_priority (priority),
  INDEX idx_assigned_to (assigned_to),
  INDEX idx_created_at (created_at)
);
```

### ticket_messages 表
```sql
CREATE TABLE ticket_messages (
  id CHAR(36) PRIMARY KEY,
  ticket_id CHAR(36) NOT NULL,
  
  sender_type ENUM('用户','客服','系统'),
  sender_id CHAR(36),
  
  message_type ENUM('text','image','video','file'),
  content TEXT,
  attachment_url VARCHAR(500),
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  
  FOREIGN KEY (ticket_id) REFERENCES tickets(id) ON DELETE CASCADE,
  INDEX idx_ticket_id (ticket_id)
);
```
