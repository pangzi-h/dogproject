# 宠物寄养小程序 - PRD 文档导航

**项目**: 边牧寄养专业平台  
**平台**: 微信小程序  
**版本**: MVP v1.0  
**更新时间**: 2026-03-26  

---

## 🎯 项目总览

本项目包含 **7 个核心模块**，每个模块都有详细的 PRD 设计文档。所有模块遵循统一的设计理念：
- **简洁高效** - 不过度设计，降低用户学习成本
- **差异化** - 相比竞品突出专业、透明、可信
- **数据透明** - 每日反馈、积分红利、价格清晰

---

## 📚 模块文档清单

### 📌 MOD-001: 用户认证与档案管理
**优先级**: P0 | **实现周期**: 2 周

[详细文档](./PRD-MOD-001-Auth-Profile.md)

**核心功能**:
- 微信授权登录 + 手机号绑定
- 个人档案编辑
- 多宠物档案管理 (基础+健康+行为信息)
- 疫苗、药物记录管理

**竞品差异**:
- 比 58 宠物更专业的宠物档案字段
- 比宠那么萌更简洁的 UI 流程
- 独家亮点：行为档案 + 禁忌特殊需求

**API 数量**: 10+  
**数据表**: 5 个 (users, pet_profiles, vaccine_records, medicine_records)

---

### 📌 MOD-002: 寄养预订系统
**优先级**: P0 | **实现周期**: 2 周

[详细文档](./PRD-MOD-002-Booking.md)

**核心功能**:
- 4 步预订流程 (日期 → 套餐 → 宠物 → 支付)
- 库存实时检查和动态展示
- 微信支付集成 + 回调处理
- 价格动态计算 (会员折扣 + 积分抵现)
- 快速重复预订

**竞品差异**:
- 比竞品更快的预订流程 (4 步 vs 5-6 步)
- 透明的价格计算过程
- 库存充足时倒计时提示

**API 数量**: 8+  
**数据表**: 3 个 (orders, order_capacity, order_payments)

---

### 📌 MOD-003: 每日反馈系统
**优先级**: P0 | **实现周期**: 2 周

[详细文档](./PRD-MOD-003-Feedback.md)

**核心功能**:
- 套餐差异化反馈 (基础: 文字, 标准: 图文, VIP: 视频)
- 反馈模板预设 (活动、进食、排便、情绪等)
- 用户反馈查看 (时间线、详情页、历史查询)
- 寄养人简化填写界面
- 反馈质量评分 + 平台展示机制

**竞品差异**:
- 唯一能做到"专业评价"的平台 (自动生成宠物表现总结)
- 反馈频率 vs 用户体验的最优平衡
- 寄养人零学习成本的表单设计

**API 数量**: 6+  
**数据表**: 3 个 (daily_feedbacks, feedback_photos, + video)

### 📌 MOD-004: 订单管理系统
**优先级**: P0 | **实现周期**: 1.5 周

[详细文档](./PRD-MOD-004-Order-Management.md)

**核心功能**:

**API 数量**: 5+

### 📌 MOD-005: 会员与积分系统
**优先级**: P1 | **实现周期**: 2 周

[详细文档](./PRD-MOD-005-Membership-Points.md)

**核心功能**:
- 4 级会员等级 (普通/银卡/金卡/钻石)
- 自动升级机制 (基于消费额)
- 简化积分规则 (1 元 = 1 分, 100 分 = ¥10)
- 积分获得多元化 (订单完成、邀请、评价、签到)
- 积分过期管理 (2 年自动清零)
- 生日优惠、免费狗粮等权益

**商业价值**:
- 会员折扣提升复购率 (9.5 折 ~ 8.5 折)
- 积分激励鼓励用户评价和分享
- 数据驱动的用户分层管理

**API 数量**: 5+  
**数据表**: 4 个 (membership_stats, membership_level_history, points_transaction)

## 🏗️ 技术架构简览

### 后端技术栈
```
框架: Java 11 + Spring Boot 2.7.x
数据库: MySQL 5.7 (Master-Slave)
缓存: Redis 6.x (会话、订单缓存、消息队列)
存储: Aliyun OSS (图片/视频)
支付: 微信支付 API
部署: Aliyun ECS (2核 2GB 起)
```

### 前端技术栈
```
框架: uni-app (支持微信小程序 + App)
UI 组件库: uView2
开发语言: JavaScript ES6+
构建工具: webpack / Vite
```

### 微服务架构
```
User Service        → 用户信息、档案管理
Order Service       → 订单创建、管理
Payment Service     → 支付处理、回调
Feedback Service    → 每日反馈管理
Membership Service  → 会员等级、积分
Service Service     → 帮助中心、工单
Shop Service        → 商品、购物车、商城订单、库存

共享中间件:
- Redis (消息队列、缓存层)
- MySQL (数据持久化)
- Aliyun OSS (文件存储)
```

## 🔒 安全与合规

### 数据安全
- SSL/TLS 传输加密
- 手机号、支付信息加密存储
- SQL 注入防护 (参数化查询)
- XSS 防护 (输入验证)

### 支付安全
- 微信支付 SDK 官方集成
- 签名验证 (每个回调)
- 幂等性保证 (重复支付检测)
- 金额再次验证

### 隐私保护
- 用户隐私条款公示
- 数据删除政策 (用户主动 + 自动清理)
- 积分不涉及真实金钱流向
- 工单消息加密存储

## 💡 创新亮点

### 与竞品的差异
1. **专业的宠物档案** - 针对中大型犬的专业字段 (vs 竞品通用)
2. **透明的价格机制** - 会员折扣和积分清晰可见 (vs 竞品黑盒)
3. **精准的每日反馈** - 套餐差异化 + 专业评价 (唯一同类)
4. **简化的会员体系** - 一看就懂 (vs 竞品复杂的等级规则)
5. **实时库存展示** - 防止用户 "预订错觉"
6. **寄养 + 商城联动** - 从服务信任延伸到高频用品复购

### 运营杠杆
- **积分激励** - 驱动用户留评、分享、复购
- **会员升级感** - 打造消费成就感和期待感
- **反馈质量评分** - 激励寄养人提高服务质量
- **每日推送** - 建立用户 "期待看反馈" 的习惯
- **精选商城** - 用刚需狗粮和用品提升客单价与复购频次

## 🎯 快速开始

### 查看特定模块
1. 选择感兴趣的模块
2. 打开对应的 PRD 文档

### 开发流程建议
1. 从 MOD-001 (认证) 开始
2. 并行 MOD-002 (预订) 和 MOD-004 (订单)
3. 依次接入 MOD-003 (反馈)、MOD-005 (会员)
