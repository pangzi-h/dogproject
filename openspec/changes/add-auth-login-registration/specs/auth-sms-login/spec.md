## ADDED Requirements

### Requirement: 发送短信验证码
系统 SHALL 支持向手机号发送 6 位数字验证码，验证码有效期为 5 分钟，同一手机号 60 秒内只能发送一次。

#### Scenario: 成功发送验证码
- **WHEN** 用户请求向手机号 `13800138000` 发送验证码
- **THEN** 系统生成 6 位数字验证码，存入 Redis（Key = `verify:phone:13800138000`），TTL = 300 秒，并调用阿里云 SMS API 发送

#### Scenario: 60秒内重复请求
- **WHEN** 用户在 60 秒内再次请求向同一手机号发送验证码
- **THEN** 系统返回错误码 `FREQUENCY_LIMITED`，提示 "请稍后再试"

#### Scenario: 手机号格式错误
- **WHEN** 用户请求向格式错误的手机号（如 `123`）发送验证码
- **THEN** 系统返回错误码 `INVALID_PHONE`，提示 "手机号格式不正确"

### Requirement: 手机号验证码注册
系统 SHALL 支持通过手机号 + 验证码完成用户注册。

#### Scenario: 成功注册（新用户）
- **WHEN** 用户提交手机号 `13800138000` 和正确验证码 `123456`
- **THEN** 系统校验验证码正确，Redis Key `verify:phone:13800138000` 存在且未过期，创建新用户记录（phone = `13800138000`），删除 Redis 中的验证码，签发 JWT Token 返回给前端

#### Scenario: 验证码错误
- **WHEN** 用户提交手机号 `13800138000` 和错误验证码 `000000`
- **THEN** 系统返回错误码 `INVALID_CODE`，提示 "验证码错误"

#### Scenario: 验证码过期
- **WHEN** 用户提交手机号 `13800138000` 和已过期的验证码
- **THEN** 系统返回错误码 `CODE_EXPIRED`，提示 "验证码已过期，请重新获取"

#### Scenario: 验证码已使用
- **WHEN** 用户提交手机号 `13800138000` 和已使用过的验证码
- **THEN** 系统返回错误码 `CODE_USED`，提示 "验证码已使用"

### Requirement: 手机号验证码登录（已注册用户）
系统 SHALL 支持已注册用户通过手机号 + 验证码登录。

#### Scenario: 成功登录（已注册用户）
- **WHEN** 已注册用户（phone = `13800138000`）提交正确验证码
- **THEN** 系统校验通过，签发 JWT Token 返回给前端

#### Scenario: 未注册用户尝试登录
- **WHEN** 未注册用户提交手机号 `13800138000` 和正确验证码
- **THEN** 系统自动创建新用户并登录（同注册流程）
