**产品名称**: 边牧寄养  
**平台**: 微信小程序  
**当前版本**: v1.1 (MVP+商城增强)  
**更新日期**: 2026-03-26

## 一、产品简介

「边牧寄养」是一款专为中大型犬主人打造的专业寄养预订微信小程序，服务范围覆盖郑州本地，提供**上门接送 + 专业寄养**一站式服务。

不同于平台撮合类产品，我们自主运营寄养基地，以**透明、专业、有温度**的服务体验帮助宠物主人安心将爱犬托付出门。

边牧寄养小程序

### 🔐 模块一：用户登录与注册

#### 功能描述

用户通过微信授权即可一键注册登录，无需填写复杂信息，同时支持绑定手机号接收订单通知。

#### 核心功能

| 功能 | 说明 |
|------|------|
| 微信一键授权 | 读取微信头像、昵称，自动完成注册 |
| 手机号绑定 | 绑定后可接收订单确认、反馈推送 |
| 自动登录 | Token 有效期 7 天，重新打开自动进入 |
| 安全退出 | 清除本地会话，保护账户安全 |

#### 用户体验

- **注册耗时 < 3 秒**，无需填写任何表单
- 首次使用可选择跳过手机绑定，预订时再引导绑定
- 登录状态稳定，减少重复登录打扰

### 🐾 模块二：宠物档案管理

#### 功能描述

用户可在小程序内为名下所有宠物创建独立档案，包含基础信息、健康信息和行为信息，是寄养预订的重要基础。

#### 三类信息维度

**① 基础信息**

| 字段 | 说明 |
|------|------|
| 宠物名称 | 必填 |
| 品种 | 边牧、金毛、拉布拉多等预设 + 自定义 |
| 性别 | 公 / 母 |
| 出生日期 | 自动计算年龄 |
| 体重 | 精确到 0.1 kg |
| 宠物照片 | 封面识别，预订和反馈均展示 |

**② 健康信息**

| 字段 | 说明 |
|------|------|
| 疫苗记录 | 可添加多条：疫苗类型 + 接种日期 + 有效期 |
| 过敏物质 | 多选：鸡肉、谷物、乳制品等，支持自定义 |
| 常用药物 | 药物名称 + 用途 + 用法 + 备注 |
| 健康状况备注 | 自由文本，如"肠胃敏感" |

**③ 行为信息**

| 字段 | 说明 |
|------|------|
| 性格特征 | 多选：活泼/温和/胆小/好奇心强等 |
| 与陌生人相处 | 单选：非常友好 / 需要适应 / 不喜欢 |
| 行为笔记 | 记录特殊习惯，如"容易分离焦虑" |
| 训练情况 | 记录已掌握的指令 |
| 禁忌与特殊需求 | 记录不能触碰的雷区 |

#### 多宠物支持

- 支持创建多个宠物档案，每只独立管理
- 预订时快速选择对应宠物，档案信息自动带入
- 删除档案后历史订单记录仍保留

### 📅 模块三：寄养预订

#### 功能描述

用户通过简洁的 4 步流程完成寄养预订，系统实时检查库存并展示价格，支付后立即确认。

#### 预订流程（4 Steps）

```
Step 1  选择时间
  选择入院/出院日期，系统检查库存，展示实时价格

  ↓

Step 2  选择服务套餐
  3 种套餐对比选择（基础/标准/VIP），会员折扣自动计算

  ↓

Step 3  选择宠物
  从已有档案中选择，档案信息自动关联

  ↓

Step 4  确认订单 & 支付
  汇总信息 + 价格明细 + 添加备注 → 微信支付
```

#### 三大服务套餐

| 套餐 | 价格 | 遛狗次数 | 每日反馈 | 特色 |
|------|------|---------|---------|------|
| **基础寄养** | ¥60/天 | 2 次 | 无 | 经济实惠 |
| **标准寄养** ⭐推荐 | ¥100/天 | 3 次 | 图文反馈 | 性价比最高 |
| **VIP 寄养** | ¥150/天 | 4 次 | 视频反馈 | 单间 + 专业互动 |

#### 价格计算逻辑

```
最终价格 = 单价 × 天数 × 会员折扣 - 积分抵现
```

- **会员折扣**：银卡 9.5 折 / 金卡 9 折 / 钻石 8.5 折
- **积分抵现**：100 积分 = ¥10，最高抵扣订单金额的 50%

#### 库存管理

- 日历灰色日期 = 已满，账号不可预订
- 库存不足时提示替代日期
- 支持申请等待列表，库存释放时通知

### 💳 模块四：订单管理

#### 功能描述

用户可查看所有订单记录，追踪寄养进度，申请取消与退款，并支持快速重复预订。

#### 订单生命周期

```
待支付 → 已支付 → 寄养中 → 待取货 → 已完成
                ↘ 取消申请 → 退款中 → 已退款
```

#### 核心功能

**订单列表**
- 按状态筛选：全部 / 寄养中 / 已完成 / 已取消
- 按时间范围筛选：近 3 个月 / 半年 / 全部
- 每张订单卡片展示关键信息 + 进度条

**订单详情**
- 完整的价格明细（原价 / 折扣 / 积分 / 实付）
- 可视化时间线（创建 → 支付 → 入院 → 出院）
- 反馈进度（已收到 N/M 天反馈）
- 寄养人信息与评分

**取消与退款**

| 场景 | 退款政策 |
|------|---------|
| 寄养开始前 24 小时内 | 全额退款，1-3 个工作日到账 |
| 寄养进行中 | 申请审批，可能产生服务费 |
| 已完成订单 | 无法取消 |

**快速重复预订**
- 已完成订单支持一键「再次预订」
- 自动预填套餐、宠物和建议时间
- 用户可修改任意字段后继续支付

### 📷 模块五：每日反馈

#### 功能描述

寄养进行期间，寄养人员每天发布宠物的日常状态记录，用户可实时查看，解决"宠物在外是否安全"的核心焦虑。

#### 反馈内容维度

每条反馈包含以下信息：

| 维度 | 内容 |
|------|------|
| 📸 照片 | 最多 3 张当日实拍 |
| 📋 活动记录 | 早晨散步 / 游戏互动 / 午休等 |
| 🍽️ 进食状况 | 早中晚三餐状态：正常 / 偏少 / 拒食 |
| 💧 饮水 | 正常 / 偏少 / 过多 |
| 💩 排便 | 次数 + 状态：正常 / 偏干 / 腹泻等 |
| 😊 情绪与行为 | 非常开心 / 正常 / 焦虑等 |
| 🎤 今日备注 | 寄养人的文字描述 |

#### 套餐差异化

| 套餐 | 反馈频率 | 反馈形式 |
|------|---------|---------|
| 基础寄养 | 1 次/天 | 纯文字 |
| 标准寄养 | 1-2 次/天 | 图文（≥1 张照片） |
| VIP 寄养 | 2-3 次/天 | 图文 + 短视频（5-30 秒） |

#### 用户通知

- 反馈发布后 **5 秒内**推送微信服务通知
- 通知预览心情 + 进食状态，一眼看懂
- 点击通知直接进入该条反馈详情

### 🏅 模块六：会员等级系统

#### 功能描述

用户累计消费满足阈值后自动升级会员等级，享受更高折扣和专属权益，无需手动申请。

#### 四大等级

| 等级 | 升级条件 | 折扣 | 专属权益 |
|------|---------|------|---------|
| 普通 | 默认 | 无折扣 | 基础服务 |
| 🥈 银卡 | 消费满 ¥500 | 9.5 折 | 生日优惠 + 优先预订 |
| 🥇 金卡 | 消费满 ¥1,500 | 9 折 | 银卡权益 + 专属客服 |
| 💎 钻石卡 | 消费满 ¥3,000 | 8.5 折 | 金卡权益 + 免费狗粮 1 个月/年 |

#### 升级机制

- 统计**已完成订单**的实际支付金额（退款不计）
- **自动升级**：订单完成时实时检测，满足阈值立即升级
- **升级通知**：推送恭喜消息 + 赠送升级奖励积分
- **只升不降**：升级后永久保持该等级
- **年度续期**：每年 1 月 1 日检查消费，自动续期

### ⭐ 模块七：积分系统

#### 功能描述

用户消费即获积分，积分可在下次预订时抵现，形成消费闭环。规则简单透明，100 积分 = ¥10。

#### 积分获得方式

| 来源 | 积分规则 |
|------|---------|
| 订单完成 | 实付金额 × 积分倍数 |
| 评价奖励 | 留评 +50 分，4 星以上额外 +25 分 |
| 邀请新用户 | 邀请人 +100 分，被邀请人 +100 分 |
| 签到奖励（v1.1）| 每日 +5 分，连续 7 天 +50 分 |

**积分倍数**（按会员等级）：普通 1×、银卡 1.2×、金卡 1.5×、钻石 2×

#### 积分使用规则

| 规则 | 说明 |
|------|------|
| 兑换比例 | 100 积分 = ¥10 |
| 使用上限 | 每次预订最多抵扣订单金额的 50% |
| 有效期 | 2 年，优先扣减最快过期的积分 |
| 使用时机 | 在预订 Step 4 确认订单时灵活选择使用数量 |

#### 积分明细页

- 实时展示当前积分余额和可兑换金额
- 即将过期积分单独提示，避免浪费
- 每笔获得/使用记录详细展示（来源 + 时间 + 变动余额）

### 🛎️ 模块八：帮助中心与客服

#### 功能描述

提供多层次的用户支持体系，80% 问题可在帮助中心自助解决，剩余问题通过在线客服或工单快速响应。

#### 帮助中心

- **6 大分类**：账户登录 / 预订支付 / 取消退款 / 每日反馈 / 积分会员 / 寄养安全
- **20+ 文章**：图文并茂，含操作截图
- **全文搜索**：支持关键词搜索，快速定位答案
- **有用评价**：每篇文章可评价是否有帮助

#### 在线客服

| 类型 | 响应时间 | 说明 |
|------|---------|------|
| 机器人客服 | 即时 | FAQ 自动匹配，24 小时可用 |
| 人工客服 | ≤ 5 分钟 | 工作时间 09:00-21:00 |
| 工作时间外 | 次日回复 | 留言后上班第一时间处理 |

#### 工单系统

当问题无法通过帮助中心解决时，用户可提交工单，系统按优先级分配处理：

| 优先级 | 场景 | 首次响应 |
|------|------|---------|
| 低 | 功能建议 | 24 小时内 |
| 中 | 一般问题 | 8 小时内 |
| 高 | 订单/退款异常 | 2 小时内 |
| 紧急 | 宠物安全问题 | 30 分钟内 |

工单支持图片/视频上传，全程可追踪处理进度，问题解决后可评价服务质量。

## 六、用户使用流程总览

### 新用户首次预订

```
打开小程序
  → 微信一键授权
  → 进入首页
  → 点击"立即预订"
  → Step 1: 选择 2026-04-15 ~ 04-20
  → Step 2: 选择标准寄养 (¥100/天)
  → Step 3: 点击"创建宠物档案" → 填写小黑的信息
  → Step 4: 确认 5 天 × ¥100 = ¥500 → 微信支付
  → 接收确认通知
  → 每天查看反馈推送
  → 04-20 接回小黑
  → 获得 500 积分 + 邀请评价
```

### 老用户再次预订

```
打开小程序
  → 自动登录（有 Token）
  → 首页看到"上次预订小黑，再次预订？"推荐卡
  → 点击再次预订 → 预填配置
  → 修改日期 → 确认 → 支付
  → 完成（全程 < 1 分钟）
```

## 七、安全性说明

| 类型 | 措施 |
|------|------|
| 登录安全 | JWT Token + 微信 code 一次性验证 |
| 数据传输 | 全程 HTTPS 加密 |
| 手机号保护 | 加密存储，展示时脱敏（138****8000）|

| 宠物照片 | 上传至阿里云 OSS，仅用户本人可查看 |
| 恶意请求 | API 频率限制 + 鉴权中间件 |
