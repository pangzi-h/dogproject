# 管理后台框架设计方案

**项目名称**: 边牧寄养 - 后台管理系统  
**版本**: v1.0  
**创建日期**: 2026-03-27  
**目标交付**: 二期（上线后 2-3 个月启动）  
**备注**: 本方案为架构规划，实施在小程序 MVP 稳定后进行

---

## 一、产品定位

### 用户角色

| 角色 | 权限范围 | 主要功能 |
|------|---------|---------|
| **运营管理员** | 全部订单、反馈、商品、用户管理 | 数据分析、内容管理、客服 |
| **寄养人员** | 所属订单、反馈发布、日常记录 | 填写反馈、上传图片、查看备备注 |
| **财务人员** | 订单明细、营收数据、对账 | 费用审核、结算、报表导出 |
| **超级管理员** | 全局系统配置、人员管理、权限 | 系统设置、日志查看、备份 |

### 核心场景

```
寄养订单管理 → 接单、排期、调配人力
每日反馈发布 → 图片/视频上传、评价打分
商品库存管理 → SKU 配置、库存变动、促销
财务对账     → 订单收入、提现、税务报表
客户服务     → 工单追踪、客户沟通、反馈处理
数据分析     → 业务 KPI、用户分析、趋势预测
```

## 二、技术栈规划

### 前端

```
框架: Vue 3.x (Composition API)
UI 库: Element Plus 或 Ant Design Vue
图表库: ECharts
表单处理: VeeValidate 3.x
HTTP 客户端: Axios
状态管理: Pinia (Vue 3 新推荐)
包管理: npm / yarn
构建工具: Vite (更快编译)
```

### 后端

```
与用户端共用同一个 Spring Boot 微服务系统
额外新增模块:
- admin-api-gateway (管理端 API 网关)
- admin-service (管理操作日志、权限管理)
- report-service (数据报表、BI 分析)

通过 Spring Security 的不同角色权限来区分
```

### 部署

```
容器化: Docker
编排: Docker Compose (开发) / Kubernetes (生产)
前端 CDN: Aliyun CDN
后端: Aliyun ECS
数据库: Aliyun RDS MySQL
缓存: Aliyun Redis
对象存储: Aliyun OSS
```

## 四、核心功能模块规划

### 1. 仪表板 (Dashboard)

**关键指标卡片**
```
- 今日订单数 / 同比增长
- 本月营收 / 目标进度
- 待处理工单 / 平均响应时间
- 在线用户数 / 活跃度
```

**图表展示**
```
- 近 30 天订单趋势（折线图）
- 服务套餐分布（饼图）
- 会员等级分布（柱状图）
- 实时订单状态分布（甜甜圈图）
```

### 2. 订单管理

**订单列表**
- 支持按状态、日期、用户、宠物品种筛选
- 快速操作：查看详情、分配寄养人、确认入院、标记出院
- 批量操作：导出、打印、转移

**订单详情**
- 用户信息、宠物信息、服务详情
- 每日反馈时间线（图片、视频、评分）
- 费用明细、优惠券使用情况
- 工单记录、备注历史

### 3. 每日反馈管理

**反馈模板**
- 反馈字段预设（进食、活动、行为、健康）
- 评分标准配置
- 寄养人端快速填写

**反馈审核**
- 反馈列表 (按审核状态、订单、寄养人)
- 反馈详情查看 + 评分
- 不合格反馈退回处理

### 4. 商品管理

**商品编辑**
- 新增/编辑商品：名称、描述、图片、tag
- 规格 SKU 配置：尺寸、价格、成本
- 库存管理：初始库存、预警库存、实时库存
- 分类和搜索优化字段

**促销配置**
- 会员价设置 (按等级)
- 活动价设置 (按时间)
- 限时优惠与库存限制

**库存操作**
- 实时库存查看
- 库存调整（进货、盘损、赠送）
- 库存日志追踪

### 5. 用户管理

**用户列表**
- 支持按等级、消费金额、激活状态筛选
- 快速操作：查看详情、发送消息、调整等级、禁用账户

**用户详情**
- 个人信息、联系方式
- 宠物档案列表
- 订单历史、消费统计
- 会员等级、积分余额
- 进度和操作日志

### 6. 财务数据

**收入统计**
- 日/周/月收入 vs 目标
- 服务收入 vs 商品收入分布
- 用户留存与复购金额

**对账管理**
- 订单对账：订单号、金额、支付状态、对账状态
- 退款审核：退款原因、金额、状态
- 财务报表导出 (CSV / Excel)

**结算单**
- 按月生成结算单
- 支付方式、税率配置
- 导出与打印

### 7. 数据报表

**用户报表**
- 新注册用户趋势
- 用户留存率分析
- LTV (生命周期价值)
- 用户分群分析

**订单报表**
- 订单金额分布
- 平均客单价、复购率
- 订单来源分析

**商品报表**
- SKU 销售排行
- 库存周转率
- 利润率分析

### 8. 系统设置

**基础设置**
- 平台名称、logo、联系方式
- 服务套餐配置 (价格、备注)
- 会员等级配置

**人员管理**
- 添加/删除员工账号
- 角色分配 (运营/寄养/财务/管理员)
- 权限细粒度配置

**内容管理**
- 帮助中心文章编辑
- Banner/公告管理
- 模板库管理

**系统日志**
- 操作日志查看（用户、操作、时间、结果）
- 错误日志排查
- 数据备份与恢复

## 五、权限制度

### 基于角色的访问控制 (RBAC)

```javascript
// 权限配置示例
const permissions = {
  order_view: '查看订单',
  order_edit: '编辑订单',
  order_delete: '删除订单',
  order_export: '导出订单',
  product_manage: '管理商品',
  finance_view: '查看财务',
  user_manage: '管理用户',
  system_config: '系统设置'
}

const roles = {
  operator: ['order_view', 'order_edit', 'product_manage'], // 运营
  staff: ['order_view', '反馈发布'], // 寄养员  
  finance: ['order_view', 'finance_view', 'order_export'], // 财务
  admin: ['*'] // 管理员
}
```

### 权限检查指令

```vue
<!-- 模板中使用 -->
<button v-permission="['order_edit']">编辑订单</button>

<!-- 只有 order_edit 权限才会显示 -->
```
